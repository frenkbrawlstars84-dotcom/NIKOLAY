# Восстановленная последовательность NIKOLAY

## Маршрут

1. Первый заход: самостоятельный fullscreen-слой с чёрной дырой TON 618. Главный экран и остальное портфолио в этот момент **не смонтированы**.
2. Автоматическое погружение камеры в исходную чёрную дыру.
3. Продолжение движения через объёмные звёзды и процедурные галактики. Вторая чёрная дыра не создаётся.
4. Замедление, мягкое завершение вступления, удаление слоя и появление главного экрана «За пределами обычного» с энергетическим порталом.
5. Прокрутка проводит через портал прямо к проектам. В Scene.tsx нет импорта BlackHole, шейдера линзирования, horizon-shade или подписи TON.
6. Существующее портфолио с AURA BEAUTY, NEXORA DIGITAL, YOUR NEXT IDEA, узлом, стеклянным объектом, кубиком и @yuniorqq сохранено.

Вступление управляется временем (`introFrame`), не прокруткой. Нормальная продолжительность — 7.6 с после готовности рендера. Сразу доступна видимая кнопка **«Пропустить»**, также работает Escape. Пока загружается WebGL, отображается SVG чёрной дыры; ошибка загрузки/рендера включает конечный fallback. При reduced motion используется короткая смена статичных стадий. Фоновая вкладка не расходует время анимации.

## Сессия и проверка

Используется только ключ `nikolay:intro:seen:v1` со значением `1` в **sessionStorage вкладки**. Он записывается после окончания или пропуска. Инициализация и StrictMode не записывают флаг; старые ключи не учитываются.

- Обычный первый заход: удалить текущий ключ и перезагрузить адрес без previewIntro.
- Повторный заход с этим ключом: сразу главный экран, модуль IntroCanvas не загружается.
- `/?previewIntro=1`: принудительно показывает интро даже при записанном флаге. Пока параметр остаётся в URL, перезагрузка снова запускает его.

Команда DevTools для чистого захода:

```js
sessionStorage.removeItem('nikolay:intro:seen:v1')
location.href = location.pathname
```

Запрет storage не вызывает ошибку и не блокирует пропуск/завершение. При таком запрете сохранять просмотр между перезагрузками браузер не позволяет.

## Удаление ресурсов

IntroCanvas существует только внутри OpeningIntro. На завершении/пропуске удаляется вся ветка DOM/React: iframe или невидимого слоя не остаётся. BlackHole освобождает render target, текстуру, материалы и геометрию; StarFlight освобождает BufferGeometry и материал. R3F освобождает renderer и теряет ненужный WebGL-контекст. RAF, обработчики событий и таймер загрузки снимаются. Body/html overflow восстанавливается.

Браузерный тест проверяет фактические `deleteFramebuffer`, `deleteTexture`, событие потери контекста и отсутствие новых draw calls после удаления. При прокрутке отдельный портал Canvas не компилирует шейдер TON_RAY_SCENE.

## Выполненные проверки

- `npm run build`: TypeScript/Vite успешно.
- `npm run test:models`: 21 passed, 0 failed. В том числе проверены session flags, принудительный повтор, отсутствие записи при инициализации, конечный автономный маршрут, отсутствие второй чёрной дыры и замедление прибытия.
- `scripts/check-intro.mjs`: desktop 1280×800 и mobile 390×844. Перед первым скриптом приложения sessionStorage явно очищен, затем добавлены старые флаги для проверки их независимости. Все пять требуемых сценариев прошли: первый заход, автоматическое окончание с hero, портал при скролле, повторный заход, previewIntro=1.
- Дополнительно проверены кнопка пропуска, сохранение проектов и Telegram, отсутствие раннего hero, родное разрешение render target, реальное свечение диска, освобождение GPU, блокировка storage и отказ импорта интро без блокировки сайта.
- Общий `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser`: прошёл полностью. Проверены dev/production, повторные загрузки, прямой/обратный проход через портал, мобильная навигация, открытие проектов, Telegram, пауза кубика, реальные GPU-матрицы 3D-объектов, DPR, остановка невидимых сцен и локальные fallback. Ошибок JavaScript в обычных сценариях нет.

Повторить отдельную проверку:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:intro
```

Проверка также включена в `npm run test:browser`; общие сценарии портфолио явно устанавливают флаг просмотренного интро, а отдельные сценарии первого захода используют очищенную сессию. Установки флага не скрывают проверку первого посещения.
