# Проверка цифрового путешествия NIKOLAY

Существующий проект, разделы, Telegram @yuniorqq, хромированный узел, стеклянная скульптура и кубик сохранены.

## Внесённые изменения

- `src/Scene.tsx`: те же линии спирали переходят в продольный пространственный коридор; камера проходит его, звёздные отрезки имеют настоящую глубину, линии за горизонтом скрываются. При близком плане коридор плавно исчезает, чтобы не закрывать диск.
- `src/BlackHole.tsx`: контролируемая экспозиция, слабый bloom, мелкие газовые нити, двухслойное звёздное поле. Полное разрешение Canvas и четыре октавы газа сохранены на телефонах. Устранены повторные угловые вычисления без уменьшения детализации.
- `src/ProjectScreenScene.tsx`: выбранная панель выходит вперёд и увеличивается, меняется ракурс камеры, активный экран использует исходную яркость и sRGB. Высота галереи учитывает доступную высоту экрана.
- `src/FluidText.tsx`: волнообразное раскрытие и хромированный блик; после окончания удаляются маска, transform, filter и will-change. Обычный текст не искажается.
- `src/rubikModel.ts`, `src/AccentScene.tsx`: остаток времени переносится между фазами, пауза/возобновление не сбрасывает поворачиваемую группу. Матрицы деталей не обновляются каждый кадр.
- `src/AmbientBackground.tsx`: атмосферный 2D-фон сохраняет кадр во время активной WebGL-сцены, освобождая ресурсы основному объекту.

## Замеры в браузере

Chromium, 1440×1000, DPR=1. Рендерер: **ANGLE / Vulkan SwiftShader Device (Subzero)** — программный, аппаратного GPU нет. EXT_disjoint_timer_query_webgl2 недоступен. Считались реальные clear-вызовы основного framebuffer, requestAnimationFrame, long tasks и CDP Script/LayoutDuration. Окно каждого замера — около 3.5 секунды; это короткий сравнительный профиль, не аппаратный benchmark.

| Сцена | FPS до | FPS после | JS до, мс | JS после, мс |
| --- | ---: | ---: | ---: | ---: |
| TON 618 | 4.11 | 4.01 | 23.73 | 11.72 |
| Кубик | 5.56 | 5.36 | 20.33 | 8.96 |

FPS практически не изменился; утверждать рост плавности по этим данным нельзя. Сократилось время JavaScript, LayoutDuration в обоих итоговых окнах — 0. Длинные задачи и низкая кадровая частота при малом времени JS указывают на нативную отрисовку в SwiftShader. Точное время GPU недоступно. **60 FPS и плавность на физическом GPU этой проверкой не подтверждены.** Исходные результаты — `scene-measurements.json`; повторяемый замер — `npm run profile:scenes`.

Проверка яркости одинаковой центральной области снимков TON (15–85% ширины, 20–80% высоты): доля пикселей с каналом >=245 снизилась с **4.1295% до 0%**, максимум снизился с 255 до 230. Это подтверждает устранение пересвеченных пятен в проверенном кадре; показатели не являются гарантией для каждого момента анимации.

## Выполняемые проверки

- 15 тестов геометрии/камеры/контроллера, включая разные интервалы кадров и точную фиксацию слоёв.
- TypeScript и production-сборка Vite.
- Chromium dev + production: повторная загрузка, медленная/быстрая/обратная прокрутка, резкий возврат наверх, чёткий текст после маски, меню и ссылки.
- WebGL/module/shader/context/timeout fallback без потери HTML, проектов и Telegram.
- Физическое стекло, перетаскивание скульптур, реальные GPU-матрицы экранов, мобильный DPR, единственный активный непрерывный renderer.
- Проверка QHD 2560×1440 и близкого плана; отдельная визуальная проверка 1366×768, 390×844 и 320×740.

Итог: 15 тестов прошли; npm run build завершился успешно; полный браузерный регрессионный прогон прошёл в dev и production. Дополнительный визуальный прогон подтвердил последовательность вперёд/назад, близкий план, чёткость заголовков, галерею и контакты на 1366×768, 390×844 и 320×740. Ошибок JavaScript в обычных сценариях не зафиксировано. Fallback проверен отдельными искусственными отказами.

## Обязательные незавершённые пункты

Настоящие скриншоты AURA BEAUTY и NEXORA DIGITAL не получены. Проверенный запрос к каждому Netlify-домену отклонён сетевым прокси с CONNECT 403; разрешённых пользовательских доменов в среде нет. `npm run check:captures` сообщает об отсутствии двух снимков. На экранах оставлены честно подписанные обложки, не скриншоты. Требование реальных изображений пока не выполнено.

Для завершения нужны разрешённые домены `amazing-pony-95fbe1.netlify.app` и `lambent-pudding-e679ea.netlify.app` либо реальные снимки от владельца. Скрипт захвата проверяет доступ, бренд и видимые изображения, сохраняет WebP 1600×1000 с quality=0.9, источник и SHA-256 исходного PNG. До фактического захвата эти файлы не созданы и не подменяются вымышленными изображениями.
