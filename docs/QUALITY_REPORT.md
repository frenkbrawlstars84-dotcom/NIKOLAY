# NIKOLAY — результаты доработки

Доработан существующий сайт. Навигация, проекты, металлический портал, TON 618, узел, стеклянный объект, белый кубик и Telegram @yuniorqq сохранены. Публикация не выполнялась.

## Реализовано

- У TON 618 увеличен наклон диска, усилены структурированные дуги линзирования, добавлены орбитальные нити и сдержанный температурный цвет. Разрешение render target совпадает с Canvas, все четыре октавы шума сохранены на мобильных. Дополнительного размытия нет. Арифметический hash ускоряет генерацию шума; дополнительная дуга переиспользует уже рассчитанный газ.
- После единственной чёрной дыры камера продолжает конечный обратимый путь среди звёзд и процедурных галактик. Длина scroll-интро не увеличена. Нет второй чёрной дыры или дополнительного обязательного экрана.
- Серебристо-синие ленты портала раскрываются в орбитальную структуру по клику. Один пружинный контроллер хранит положение и скорость при повторных нажатиях. Масштаб ограничен измеренной областью hero. При прокрутке клик отключается, форма плавно передаёт управление scroll-анимации.
- Для портала, узла, стекла и экранов добавлены IDLE / HOVER / ACTIVE / RETURN, короткий световой отклик, касания, Enter/Space и Escape. Перетаскивание не считается нажатием, touch-action сохраняет вертикальную прокрутку. Узел перестраивается, стеклянные грани раскрываются через GPU morph targets. Клавиатурные стрелки и вращение мышью сохранены.
- Активный экран сильнее выходит вперёд и увеличивается, кликом доступно дополнительное небольшое приближение. Исходная яркость изображения не уменьшается; сгенерированные обложки остаются явно подписаны. Геометрия рамок, поверхностей и индикаторов общая. Ссылки открытия проектов находятся в неподвижной HTML-панели и проверены как навигационные действия.
- YOUR NEXT IDEA представляет приглашение к сотрудничеству, с отдельной ссылкой на @yuniorqq. Демопроекты не названы коммерческими кейсами.
- К космическому фону добавлены кешированные спиральные галактики и скопления звёзд, серебристо-синие туманности и несколько глубин параллакса. Используется один 2D Canvas; во время активного WebGL фон сохраняет кадр.
- Кубик выполняет шесть ходов и их точную обратную последовательность. Четверть-поворот — 0.34 с; пауза между циклами — 1.35 с. Нажатия объединяются в одну дополнительную короткую комбинацию с обратной сборкой после текущего цикла. Сохранены 26 деталей, 54 белые накладки, тонкие чёрные разделители и отсутствие отдельных кнопок. Геометрия не пересоздаётся в кадре, матрицы instance обновляются только на границах ходов. Во время хода меняется quaternion группы.
- Сохранены lazy loading, ограничение DPR, delta time, reduced motion, освобождение GPU-ресурсов и независимые fallback. Невидимые переходы не вызывают бесконечный invalidate. Устаревший таймер загрузки не переводит уже готовую сцену в fallback.

## Проверки

- `npm run build`: успешно, TypeScript + Vite. Предупреждение о крупных JS chunks сохраняется.
- `npm run test:models`: 19 passed, 0 failed, 0 skipped. Проверяются точная обратная сборка, повторные комбинации, уникальные cubies/накладки, отсутствие покадровых instance uploads, геометрия, камера и обратимые пружины.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser`: полный прогон прошёл. Dev и production, StrictMode/reload, прямое/обратное скроллирование, мобильные 390/320 px, меню, навигация проектов, Telegram, отказ WebGL/module/shader/context/timeout, пауза кубика, реальное стекло, GPU-матрицы, мобильный DPR и остановка невидимых сцен.
- `scripts/check-tactile.mjs`: desktop 1440×1000 и mobile touch 390×844 прошли. Проверены наведение, раскрытие/возврат, пять повторных нажатий, Enter/Escape, передача портала прокрутке, экраны, дополнительная комбинация и собранное состояние кубика, reduced motion и Telegram. Для повторения добавлена команда `npm run test:tactile`, запускающая свой preview.
- Мобильные hero, близкий план TON, стекло и контактная секция дополнительно просмотрены на снимках Chromium. Ошибок JavaScript в этих сценариях нет.
- После финального ускорения арифметики GLSL повторены production-сборка и браузерный профиль: shader компилируется, сцены рисуются, ошибок JavaScript нет. Полный регрессионный прогон выше выполнен до последней арифметической оптимизации шума.
- `npm run check:captures`: **failed**, отсутствуют оба реальных снимка. Это незавершённая часть задачи, а не пройденная проверка.

## Измерения

Chromium 1440×1000, DPR=1, ANGLE/Vulkan **SwiftShader**, программный рендерер. GPU timers недоступны. Перед каждым окном ожидаются 12 реальных кадров; запрошено 7 секунд измерения. Сохранена фактическая длительность, включая длинные паузы. Сравнивается исходный HEAD и текущая сборка с одинаковыми зависимостями. Это два коротких окна, не статистический benchmark и не проверка физических телефонов.

| Сцена | FPS до / после | Медиана кадра до / после, мс | Draw calls до / после |
| --- | ---: | ---: | ---: |
| TON 618 | 3.18 / 1.24 | 312.0 / 336.8 | 3 / 3 |
| Кубик | 4.44 / 4.37 | 221.6 / 218.2 | 2 / 4 |

В итоговом окне TON зафиксирована отдельная длинная задача **7249 мс**; фактическое окно растянулось до 12.11 с. Она существенно снизила средний FPS. Причина этой паузы не установлена; CDP показывает всего 18.06 мс JavaScript и 0 мс layout за окно. Скрывать паузу или выдавать медиану за стабильную плавность нельзя. У TON медиана хуже исходной примерно на 8%; отсутствие регрессии на физическом GPU **не подтверждено**.

В исходном окне кубик был в паузе (2 draw calls), в новом — выполнял быстрые ходы (4 draw calls). Это разные нагрузки; максимальный бюджет кубика остался прежним: 2 вызова в покое, 4 во время хода. Медиана итогового окна не ухудшилась, но это не подтверждает стабильные 60 FPS. Исходные данные со всеми long tasks сохранены в `scene-measurements.json`.

Суммарный JS всех чанков gzip: **432,094 → 436,363 байт**, +4,269 байт (+0.99%). Это все JS chunks, не только первый экран. Изображения проектов не добавлялись. Размеры ресурсов, число запросов и transfer bytes записаны в JSON.

- `amazing-pony-95fbe1.netlify.app`
- `lambent-pudding-e679ea.netlify.app`

После подтверждённого доступа: `npm run capture:projects`, `npm run check:captures`, `npm run build`, затем визуальная проверка полученных настоящих изображений. Сам захват в текущей задаче не выполнялся из-за подтверждённого сетевого запрета.
