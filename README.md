# Николай — портфолио веб-разработчика

NIKOLAY — Digital Experience. React, TypeScript, Vite, Tailwind CSS 4, Motion, Three.js / React Three Fiber, Drei и GSAP ScrollTrigger. Процедурная WebGL-скульптура, пространственная галерея и пять интерактивных демонстраций. Системные шрифты не требуют внешних запросов. Анимации учитывают `prefers-reduced-motion`.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm install
npm run dev
```

Vite выводит адрес сервера в терминал. Для проверки публикации:

```sh
npm run build
npm run preview
```

Сборка находится в `dist`. В ограниченной облачной среде при недоступном стандартном кеше используйте `npm install --cache /tmp/nikolay-npm-cache`. Для повторяемой установки с lockfile можно использовать `npm ci`.

## Контакты

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
VITE_TELEGRAM_URL=https://t.me/yuniorqq
```

Telegram по умолчанию — **@yuniorqq**, подтверждённый владельцем сайта. Он хранится в `src/config.ts` и выводится текстом и кнопкой. `VITE_TELEGRAM_URL` может переопределить его при публикации; пустая переменная сохраняет этот Telegram. Email не отображается: единственный канал связи — Telegram. Некорректное переопределение переменной сохраняет подтверждённый адрес @yuniorqq. Перезапустите dev-сервер или пересоберите сайт после изменения переменных. Переменные с префиксом `VITE_` публичны: не помещайте в них секреты.

## Проекты и контент

Проекты редактируются в `src/projects.ts`. Поля: `name`, `description`, `category`, `technologies`, `url`, `image`, `upcoming`. Для реального скриншота положите файл, например, в `public/projects/aura.webp` и задайте `image: '/projects/aura.webp'`. Желательно использовать WebP/AVIF шириной 1400–1800 px.

Для AURA BEAUTY сейчас показано **концептуальное превью, а не скриншот**: сайт недоступен из среды разработки из-за сетевого ограничения. Стек исходного проекта не подтверждён, поэтому он не выдуман. Замените превью настоящим скриншотом и заполните технологии после проверки. Карточка-заготовка не выдаётся за выполненный кейс.

Основной контент находится в `src/main.tsx`, стили — в `src/style.css`. SEO-заголовок и описание — в `index.html`. После появления домена можно добавить canonical и абсолютные `og:url` / `og:image`.

## Публикация на Netlify

1. Загрузите проект в свой GitHub-репозиторий и подключите его в Netlify через импорт существующего проекта.
2. Команда сборки: `npm run build`, директория публикации: `dist`. Эти настройки уже указаны в `netlify.toml` вместе с Node.js 22.
3. В настройках переменных окружения Netlify добавьте `VITE_TELEGRAM_URL`.
4. Запустите Deploy. После изменения переменных выполните новую сборку.

Также можно загрузить готовую папку `dist` через ручную публикацию Netlify. В этом случае контакты должны быть заданы перед локальной сборкой.

Это одностраничный сайт с якорной навигацией; дополнительный SPA redirect не требуется.


## 3D и анимации

В `src/Scene.tsx` — настоящая процедурная WebGL-сцена. Один Canvas сохраняется на протяжении hero и пространственного перехода. GLSL-шейдер превращает исходную спираль в цифровой коридор глубиной 38 условных единиц; камера проходит туннель и затем пересекает горизонт TON 618, частицы остаются в трёхмерном пространстве. Формой и камерой управляет прогресс прокрутки, а не только прошедшее время.

`src/useCinematicFlow.ts` задаёт порядок сцен: текст hero уходит под маску, затем открывается весь viewport, линии разворачиваются в коридор, и из движения появляется следующая секция. Начальный viewport измеряется по отдельной области справа от текста (на мобильных — под ним). Спираль не рисуется поверх основного текста. Нативная прокрутка сохраняется, перехвата колеса мыши нет. При высоте экрана до 650 px длинные закреплённые переходы заменяются обычной прокруткой и ручной навигацией галереи.

`src/ProjectGallery.tsx` — пространственная галерея HTML-плоскостей с перспективой и глубиной. Прокрутка проводит через три проекта; кнопки и стрелки позволяют выбрать нужный напрямую. Hover наклоняет всю поверхность и отдельно сдвигает изображение. Неактивные плоскости исключены из клавиатурной навигации. Изображения не подменяются фальшивыми скриншотами.

`src/FluidText.tsx` раскрывает слова через маску с мягким перспективным изгибом; на десктопе добавлено краткое размытие. Эффект выполняется один раз, после него остаётся читаемый HTML-текст. На мобильных размытие отключено.

### Производительность и доступность

Сцена загружается отдельным динамическим модулем. Desktop: 76 линий × 168 сегментов, 220 частиц, DPR не выше 1.5, до 60 кадров/с. Mobile / мало ядер CPU: 36 × 104, 80 частиц, DPR=1, до 30 кадров/с. На сцену приходится два draw calls (линии и точки); дорогих постэффектов нет. Вне экрана, в скрытой вкладке и по PAUSE непрерывный рендер останавливается. Геометрия и материалы освобождаются при размонтировании.

При `prefers-reduced-motion` 3D и фон статичны, закреплённых scroll-проходов нет, слова не искажаются, проекты переключаются кнопками без наклонов. Без WebGL2 или при ошибке Canvas доступна статичная SVG-графика, содержание и ссылки работают.

`src/AmbientBackground.tsx` добавляет периферийные частицы и мягкие световые линии одним 2D-canvas без второго WebGL-контекста. Центр оставлен свободным для чтения. Фон также учитывает PAUSE, скрытую вкладку, мощность устройства и reduced motion.

Все эффекты работают локально, без платных API и внешних 3D-моделей. Vite может предупреждать о размере динамического 3D-модуля, содержащего Three.js: это не ошибка сборки. Скорость на реальных телефонах зависит от GPU; эмуляция мобильного viewport в Chromium не заменяет проверку на физических устройствах.

NEXORA DIGITAL опубликован по адресу https://lambent-pudding-e679ea.netlify.app/. В галерее есть кнопка открытия сайта; обложка явно подписана как обложка, а не скриншот. Сетевой доступ к Netlify из среды разработки ограничен, поэтому описание нейтральное, а стек не выдуман. Для замены обложки добавьте настоящий скриншот через поле `image`. Только «Следующая история» остаётся заготовкой без ссылки. AURA BEAUTY сохранён как демопроект с честно подписанным концептуальным превью. В финальном блоке — только @yuniorqq, прямая ссылка и кнопка «Связаться со мной».

## Исправление чёрного экрана в режиме разработки

Причина была в `useCinematicFlow.ts`: при повторном запуске / очистке эффектов в React StrictMode GSAP вызывал функцию вычисления `clipPath`, а та читала `anchor.current!.getBoundingClientRect()`. Ref к этому моменту уже мог быть `null`, исключение размонтировывало React-приложение целиком. В production-preview очистка эффектов не повторяется так же, поэтому одной сборки для обнаружения было недостаточно.

Теперь эффект захватывает свои DOM-элементы, проверяет подключение к документу и при очистке возвращает последнее корректное значение маски. Callback ResizeObserver защищён от работы после удаления эффекта. StrictMode сохранён.

`SceneLayer.tsx` изолирует ленивый импорт 3D-модуля внешним ErrorBoundary. Статичный SVG fallback из `SceneFallback.tsx` доступен независимо от Three.js. Неподдерживаемый WebGL, ошибка renderer / шейдера, потеря GPU-контекста или запуск, не завершившийся за 10 секунд, отключают только 3D. Пока реальный первый кадр не отрисован, контент не скрывается ради пространственного прохода. При отказе сцены закреплённый проход отключается, текст восстанавливается, все ссылки и галерея доступны. Canvas не перехватывает события мыши.

### Повторяемая проверка в браузере

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

Тест собирает production и сам запускает отдельные Vite dev / preview на портах 5175 и 4175. Проверяет повторную загрузку с StrictMode, прокрутку, мобильное меню, Telegram и шесть отказов: отсутствие WebGL, недоступный 3D-модуль, ошибка renderer, ошибка шейдера, потеря контекста и зависшая загрузка. При имитации сетевой или GPU-ошибки сообщения о ней в консоли ожидаемы; интерфейс должен оставаться работоспособным. После теста созданные им серверы останавливаются.

В облачной среде с уже установленным Chromium можно пропустить загрузку браузера:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

Для обычной ручной проверки выполните `npm run dev`, откройте адрес из терминала, несколько раз обновите страницу, прокрутите до проектов и Telegram. Проверяйте именно dev-сервер, а не только `npm run build`.


Ссылки проектов («Смотреть сайт» и круглая стрелка под карточкой) открываются в текущей вкладке обычным переходом браузера, без JavaScript-popup. Названия проектов в левом списке выбирают карточку. Кнопки вынесены в неподвижную HTML-панель под 3D-галереей: движение карточки не смещает область нажатия. Tilt, глубина и parallax самой карточки сохранены.


## Космическая атмосфера и акцентные сцены

`src/AmbientBackground.tsx` процедурно создаёт текстуры туманностей на небольшом offscreen-canvas, затем плавно смещает их за контентом. Здесь же — 150 далёких звёзд с разной глубиной, мягким мерцанием и parallax, а также периферийные световые линии. Никаких фотографий, сторонних изображений или платных API. На мобильных и устройствах с малым числом ядер остаются один слой облаков и 55 звёзд, обновляемых не чаще 12 раз/с; desktop-фон ограничен 25 обновлениями/с. Текст hero защищён мягкой тёмной подложкой, а viewport спирали по-прежнему отделён от текста.

`src/AccentObject.tsx` загружает `AccentScene.tsx` только при приближении к секции. В «Обо мне» — хромированная скульптура непрерывной формы; в контактах рядом с @yuniorqq — настоящий 3D-кубик Рубика. Он состоит из 26 скруглённых деталей и 54 цветных накладок, объединённых в два instanced draw calls; отдельные слои поворачиваются на 90° и сохраняют новое положение. Кубик выполнен в чёрно-белой гамме с серебристыми границами; свет и отражения создаются локально. На мобильных и слабых устройствах дополнительная скульптура заменяется статичной SVG-версией, а кубик рендерится с DPR=1 и более простой геометрией. Акцентные сцены ограничены 24 кадрами/с на mobile и 45 на desktop.

У каждой новой сцены собственные ErrorBoundary, таймаут запуска и независимый SVG fallback. Общий `src/CanvasHealth.tsx` следит за ошибками шейдера и потерей GPU-контекста. Ошибка кубика не отключает основной сайт и не скрывает Telegram. Вне viewport, в скрытой вкладке и по глобальной PAUSE рендер останавливается. При reduced motion звёзды и все 3D-объекты статичны. Геометрия, материалы, instance-буферы и сгенерированные reflection-текстуры освобождаются при размонтировании.

Браузерный регрессионный тест дополнительно проверяет отказ загрузки AccentScene и потерю WebGL-контекста кубика. Дополнительно в Chromium проверены мобильная композиция, отсутствие пересечения спирали с текстом и остановка instanced draw calls при PAUSE / уходе кубика за экран. Показатели плавности на физических устройствах зависят от GPU.


## TON 618 и точные повороты кубика

`src/BlackHole.tsx` расширяет существующий hero-Canvas: непрозрачная тёмная сфера, наклонённый аккреционный диск с процедурными полосами, фотонное кольцо и изогнутые световые линии. Спираль сначала разворачивается в туннель; затем камера приближается к сфере на глубине z=-24 и проходит сквозь неё. Краткое затемнение ограничено контейнером перехода, не перекрывает меню и не блокирует прокрутку. После выхода сразу появляется галерея проектов; «Обо мне» сохранён после неё. Общая длина прохода остаётся 245svh (220svh на мобильных), дополнительного scroll-lock нет. Ресурсы TON используют тот же WebGL-контекст, что и спираль, а не отдельную полноэкранную сцену.

У диска нет внешних текстур или тяжёлого raymarching/postprocessing. На мобильных меньше сегментов диска, сферы и линзирующих линий. При отказе шейдера TON существующий CanvasHealth включает SVG fallback и отключает кинематографическую маску, сохраняя HTML-контент. При reduced motion и низком viewport длинный проход отключён.

`src/rubikModel.ts` хранит 26 деталей на целочисленной сетке и дискретные матрицы ориентации. Во время поворота 9 выбранных деталей и их накладки получают общий quaternion; в конце выполняется один точный поворот на 90°, а новая позиция фиксируется. Автоматическая последовательность меняет оси и слои, не откатывая каждый поворот назад. Накладки чёрные и белые, границы — глянцевый серебристый материал. Вращение всего кубика и реакция на курсор сохранены. Кнопка «Повернуть грань» добавляет настоящий ручной поворот; при reduced motion он выполняется сразу, без анимации. Email отсутствует; @yuniorqq, прямая ссылка и кнопка связи ведут на https://t.me/yuniorqq.

Проверка математики отдельно:

```sh
npm run test:rubik
```

Шесть тестов проверяют количество деталей и 54 наружных накладки, обратный поворот, возврат после четырёх поворотов, сохранение решётки после 2 000 смешанных поворотов и дискретное завершение анимации. `npm run test:browser` также включает эти тесты и проверяет реальные instance-матрицы, отправленные в WebGL: ровно 9 изменённых деталей на поворот, 26 уникальных центров и возврат исходных матриц после четырёх нажатий. Дополнительно проверяются быстрая / медленная / обратная прокрутка TON и поздняя ошибка его шейдера без потери остального сайта.
