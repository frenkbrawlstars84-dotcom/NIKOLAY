# Николай — портфолио веб-разработчика

NIKOLAY — Digital Experience. React, TypeScript, Vite, Tailwind CSS 4, Motion, Three.js / React Three Fiber, Drei и GSAP ScrollTrigger. Процедурное космическое вступление, орбитальная WebGL-скульптура, пространственная галерея и пять интерактивных демонстраций. Системные шрифты не требуют внешних запросов. Анимации учитывают `prefers-reduced-motion`.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm install
npm run dev
```

Vite выводит адрес сервера в терминал. Для проверки публикации:

```sh
npm run build
npm run preview
```

Сборка находится в `dist`. В ограниченной облачной среде при недоступном стандартном кеше используйте `npm install --cache /tmp/nikolay-npm-cache`. Для повторяемой установки с lockfile можно использовать `npm ci`.

## Контакты

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
VITE_TELEGRAM_URL=https://t.me/yuniorqq
```

Telegram по умолчанию — **@yuniorqq**, подтверждённый владельцем сайта. Он хранится в `src/config.ts` и выводится текстом и кнопкой. `VITE_TELEGRAM_URL` может переопределить его при публикации; пустая переменная сохраняет этот Telegram. Email не отображается: единственный канал связи — Telegram. Некорректное переопределение переменной сохраняет подтверждённый адрес @yuniorqq. Перезапустите dev-сервер или пересоберите сайт после изменения переменных. Переменные с префиксом `VITE_` публичны: не помещайте в них секреты.

## Проекты и контент

Проекты редактируются в `src/projects.ts`. Поля: `name`, `description`, `category`, `technologies`, `url`, `image`, `upcoming`. Для реального скриншота положите файл, например, в `public/projects/aura.webp` и задайте `image: '/projects/aura.webp'`. Желательно использовать WebP/AVIF шириной 1400–1800 px.

Для AURA BEAUTY сейчас показано **концептуальное превью, а не скриншот**: сайт недоступен из среды разработки из-за сетевого ограничения. Стек исходного проекта не подтверждён, поэтому он не выдуман. Замените превью настоящим скриншотом и заполните технологии после проверки. Карточка-заготовка не выдаётся за выполненный кейс.

Основной контент находится в `src/main.tsx`, стили — в `src/style.css`. SEO-заголовок и описание — в `index.html`. После появления домена можно добавить canonical и абсолютные `og:url` / `og:image`.

## Публикация на Netlify

1. Загрузите проект в свой GitHub-репозиторий и подключите его в Netlify через импорт существующего проекта.
2. Команда сборки: `npm run build`, директория публикации: `dist`. Эти настройки уже указаны в `netlify.toml` вместе с Node.js 22.
3. В настройках переменных окружения Netlify добавьте `VITE_TELEGRAM_URL`.
4. Запустите Deploy. После изменения переменных выполните новую сборку.

Также можно загрузить готовую папку `dist` через ручную публикацию Netlify. В этом случае контакты должны быть заданы перед локальной сборкой.

Это одностраничный сайт с якорной навигацией; дополнительный SPA redirect не требуется.


## Космическое вступление и интерактивные сцены

Сценарий входа: **одна чёрная дыра → погружение → полёт сквозь галактики → сайт**. Процедурный диск вычисляется в полном разрешении Canvas. Нет видео или растянутого изображения. Газ имеет неоднородную структуру, пылевое поглощение, медно-золотистую температуру и линзированное изображение. В полёте представлены спиральные, галактики с перемычкой, эллиптические и линзовидные галактики с индивидуальными частицами, рукавами и областями звездообразования.

`CosmicIntro.tsx` обеспечивает показ один раз в сессии, «Пропустить», Escape, защитный таймер и плавное прибытие. Траектория `introJourney.ts` длится 6.35 секунды; загрузка может добавить небольшое время. При reduced motion, якорной ссылке или повторном входе сайт открывается сразу. После вступления GPU-ресурсы освобождаются. Для повторного просмотра очистите `nikolay-portal-seen-v1` в sessionStorage.

Hero сохраняет серебристо-синий объект `OrbitalNexus.tsx`. При наведении он реагирует на курсор, при нажатии раскрывает ленты и ядро. По новому заданию восстановлен проход камеры через орбитальную форму при прокрутке к проектам. Во время этого перехода клики блокируются; геометрия переходит в отдельную конфигурацию для прохода. Чёрная дыра остаётся только во вступлении. На коротких экранах, при reduced motion или отказе WebGL закрепление отключено.

Хромированный узел расплетается и возвращается обратно. Стеклянный многогранник разделяется на 9/12 закрытых объёмных фрагментов и собирается. Все формы подготовлены один раз и интерполируются на GPU. `ObjectInteraction` и `useObjectMotion` задают общий подход к времени, состояниям idle/hover/active/return и повторным нажатиям. Позиция и скорость пружины при повторном клике сохраняются. Нет React setState на каждом кадре.

`InteractiveSurface.tsx` отвечает за мышь, касания, фокус, Enter/Space и ненавязчивую подсказку. Вертикальные touch-жесты сохраняют прокрутку. Стрелки/перетаскивание вращают узел и многогранник; в reduced motion это непосредственное ручное изменение позы без автоматической анимации. При ошибке графики остаются статические версии и доступный HTML.

Общий Canvas 2D создаёт звёзды нескольких глубин, мягкие облака и параллакс. Проектные панели приближаются, наклоняются и подсвечивают края. Контактные ссылки остаются независимыми от анимаций.

## Кубик Рубика

Белые грани, тонкие чёрные разделители, без кнопок управления. Цикл: шесть ходов перемешивания → короткая пауза → шесть обратных ходов → собранное состояние. Поворот длится 0.32 секунды, пауза между ходами — 0.065, в перемешанном состоянии — 0.42, в собранном — 1.15 секунды. Нажатие ставит в очередь одну дополнительную комбинацию из трёх ходов и их обратной последовательности. Повороты не накладываются.

`rubikModel.ts` хранит целочисленные координаты и ориентации 26 деталей. `rubikRig.ts` вращает группу из девяти деталей quaternion; instance-матрицы загружаются только на границах ходов. Общее вращение — 0.25228125 рад/с, в 1.5 раза быстрее предыдущей версии. Все скорости зависят от delta time.

## Производительность

`useSceneBudget.ts` разрешает непрерывный рендер одному видимому объекту, учитывает наведение и клавиатурный фокус. Невидимые сцены сохраняют кадр. 3D загружается лениво, вступление не рендерится одновременно с основными тяжёлыми сценами. DPR и HIGH/MEDIUM/LOW учитывают устройство и frame time. Скрытая вкладка, PAUSE и reduced motion останавливают автоматическое движение.

`webglProfile.ts` определяет программный рендерер до создания материалов и кеширует результат. Для программного WebGL стекло использует лёгкую прозрачность и отражения, сохраняя ту же 3D-геометрию. На аппаратном GPU остаётся физическое преломление. Улучшение этого fallback подтверждается сравнительными замерами в отчёте. FPS физических устройств в облачной среде не проверяется.

## Проверки

```sh
npm run test:models
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:intro
```

`test:browser` сам запускает dev и production. `test:intro` сам запускает dev либо использует `INTRO_TEST_URL`. В обычной системе установите Chromium командой `npx playwright install chromium` и не задавайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

Для дополнительных проверок сначала запустите `npm run preview` в отдельном терминале:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:interactions
HERO_TEST_URL=http://127.0.0.1:4173 PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node scripts/check-premium.mjs
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run profile:experience -- http://127.0.0.1:4173
```

`test:interactions` проверяет реальные GPU-веса формы, повторные клики, обратный scroll-проход, блокировку морфинга, Enter/Space, касания, вертикальный touch-scroll и reduced motion. Профиль измеряет интро, hero, узел, многогранник, галерею и кубик без снимков во время замеров.

Актуальные результаты, ограничения и полный список файлов: [docs/INTERACTIVE_REPORT.md](docs/INTERACTIVE_REPORT.md). Предыдущие отчёты сохранены как архив версий.

## Настоящие скриншоты проектов

В `public/projects/screenshots.json` пока нет записей: в прежней среде доступ к двум сайтам Netlify блокировался. Галерея показывает честно подписанные обложки. Получение реальных снимков — отдельная контентная задача. Для неё нужны домены `amazing-pony-95fbe1.netlify.app` и `lambent-pudding-e679ea.netlify.app`, затем команды:

```sh
npm run capture:projects
npm run check:captures
npm run build
```

Скрипт проверяет HTTP-доступ и название бренда перед сохранением снимка, а затем записывает WebP и происхождение в `public/projects`. Пустой манифест по-прежнему намеренно не проходит `check:captures`; это не проверка вступления.
