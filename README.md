# Николай — портфолио веб-разработчика

NIKOLAY — Digital Experience. React, TypeScript, Vite, Tailwind CSS 4, Motion, Three.js / React Three Fiber, Drei и GSAP ScrollTrigger. Процедурная WebGL-скульптура, пространственная галерея и пять интерактивных демонстраций. Системные шрифты не требуют внешних запросов. Анимации учитывают `prefers-reduced-motion`.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm install
npm run dev
```

Vite выводит адрес сервера в терминал. Для проверки публикации:

```sh
npm run build
npm run preview
```

Сборка находится в `dist`. В ограниченной облачной среде при недоступном стандартном кеше используйте `npm install --cache /tmp/nikolay-npm-cache`. Для повторяемой установки с lockfile можно использовать `npm ci`.

## Контакты

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
VITE_TELEGRAM_URL=https://t.me/yuniorqq
VITE_EMAIL=you@example.com
```

Telegram по умолчанию — **@yuniorqq**, подтверждённый владельцем сайта. Он хранится в `src/config.ts` и выводится текстом и кнопкой. `VITE_TELEGRAM_URL` может переопределить его при публикации; пустая переменная сохраняет этот Telegram. Email в примере нужно заменить своим: реальный адрес пока не указан. Некорректные контакты не создают неработающих ссылок. Перезапустите dev-сервер или пересоберите сайт после изменения переменных. Переменные с префиксом `VITE_` публичны: не помещайте в них секреты.

## Проекты и контент

Проекты редактируются в `src/projects.ts`. Поля: `name`, `description`, `category`, `technologies`, `url`, `image`, `upcoming`. Для реального скриншота положите файл, например, в `public/projects/aura.webp` и задайте `image: '/projects/aura.webp'`. Желательно использовать WebP/AVIF шириной 1400–1800 px.

Для AURA BEAUTY сейчас показано **концептуальное превью, а не скриншот**: сайт недоступен из среды разработки из-за сетевого ограничения. Стек исходного проекта не подтверждён, поэтому он не выдуман. Замените превью настоящим скриншотом и заполните технологии после проверки. Карточка-заготовка не выдаётся за выполненный кейс.

Основной контент находится в `src/main.tsx`, стили — в `src/style.css`. SEO-заголовок и описание — в `index.html`. После появления домена можно добавить canonical и абсолютные `og:url` / `og:image`.

## Публикация на Netlify

1. Загрузите проект в свой GitHub-репозиторий и подключите его в Netlify через импорт существующего проекта.
2. Команда сборки: `npm run build`, директория публикации: `dist`. Эти настройки уже указаны в `netlify.toml` вместе с Node.js 22.
3. В настройках переменных окружения Netlify добавьте `VITE_TELEGRAM_URL` и `VITE_EMAIL`.
4. Запустите Deploy. После изменения переменных выполните новую сборку.

Также можно загрузить готовую папку `dist` через ручную публикацию Netlify. В этом случае контакты должны быть заданы перед локальной сборкой.

Это одностраничный сайт с якорной навигацией; дополнительный SPA redirect не требуется.


## 3D и анимации

`src/Scene.tsx` содержит процедурную геометрию и GLSL-шейдер серебристых линий. GSAP ScrollTrigger в `src/main.tsx` передаёт точный прогресс прокрутки сцене: изменяются форма, разлёт линий, поворот и положение камеры. Прокрутка остаётся нативной, без scroll hijacking. Объект реагирует на курсор. Кнопка PAUSE останавливает непрерывное движение; прокрутка остаётся управляемой пользователем.

Сцена загружается отдельным динамическим модулем. На телефонах и устройствах с небольшим числом ядер меньше линий и DPR=1; на десктопе DPR ограничен 1.5. Спираль находится в отдельной области справа от текста, а на экранах до 900 px — под ним. Выход сцены за эту область обрезается: текст и 3D физически не пересекаются. Заголовок больше не затухает при прокрутке. На десктопе используется один проход для 84 линий × 160 сегментов, на мобильных — 40 × 100. Частота рендера ограничена 60 кадрами/с на десктопе и 30 на мобильных. При скрытой вкладке и уходе сцены за экран непрерывный рендер отключается. При reduced motion сцена статична, а scroll-трансформации отключены. При отсутствии WebGL2 или ошибке Canvas используется честно статичная SVG-графика. Геометрия и материалы освобождаются при размонтировании. Фоновые частицы и световые линии рисуются одним 2D-canvas без дополнительного WebGL-контекста: 30 частиц / до 25 обновлений в секунду на десктопе, 12 / до 15 на телефонах. Центр страницы оставлен свободным; текст hero дополнительно защищён непрозрачной подложкой. Кнопка PAUSE останавливает и спираль, и фон. При reduced motion фон статичен, а в скрытой вкладке останавливается. Все эффекты локальные, платных API и внешних 3D-моделей нет.

Vite может предупреждать о размере отдельного 3D-модуля: он содержит Three.js и загружается отдельно от основного интерфейса. Это не ошибка сборки. Производительность на каждом реальном устройстве зависит от GPU; программная проверка Chromium не заменяет тестирование на физических телефонах.

В галерее NEXORA DIGITAL — только заготовка без ссылки, а AURA — демопроект с явно подписанным концептуальным превью. Контакты по-прежнему задаются через `.env` или переменные Netlify.
