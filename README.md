# NIKOLAY — портфолио веб-разработчика

Существующий сайт на React 19, TypeScript, Vite, Tailwind CSS 4, Motion, Three.js / React Three Fiber и GSAP. Новых зависимостей для финальной стабилизации не добавлено.

## Разработка и сборка

Нужны Node.js 22+ и npm.

```sh
npm ci
npm run dev
```

Если стандартный кеш недоступен: `npm ci --cache /tmp/nikolay-npm-cache`.

```sh
npm run build
npm run preview
```

TypeScript проверяется при сборке; результат — `dist/`. Предупреждение Vite о размере модуля с Three.js не является ошибкой сборки.

## Последовательность сайта

Единственное космическое путешествие — автоматическое вступление длительностью 5,8 секунды: чёрная дыра, короткий полёт через звёзды и три разные галактические обложки, плавное появление главного экрана. «Пропустить» доступно сразу. Запуск тяжёлой сцены ограничен 1,8 секунды: при ошибке, потере WebGL-контекста или зависшем импорте открывается основной сайт. Независимый таймер завершения не позволяет остаться в интро при остановке кадров.

Успешное завершение, пропуск и аварийный выход сохраняют `nikolay:intro-seen=1` в sessionStorage. Повторное открытие в той же вкладке пропускает интро. `?previewIntro=1` принудительно включает вступление, но не читает и не меняет обычную отметку сессии. При `prefers-reduced-motion: reduce` вступление пропускается даже в preview. При отключённом хранилище сайт продолжает работать, но запомнить просмотр между загрузками не может.

До загрузки CSS действует встроенный тёмный фон `html/body/#root`. До первого WebGL-кадра показывается статичная SVG-заставка; это графический резервный вариант, не 3D-сцена.

Чёрная дыра переиспользует существующий аналитический GLSL-эффект. Canvas и render target имеют одинаковое внутреннее разрешение; DPR ограничен 1,5 на desktop и 1 на mobile, antialias включён. Только небольшой bloom смягчается; базовый диск не растягивается из уменьшенного буфера. Галактики — три небольшие прозрачные текстуры 1024×1024, однократно нарисованные из фиксированных распределений звёзд (спираль, диск с пылевой полосой, эллиптическая форма). Они движутся в перспективе и не являются физической симуляцией. После вступления Canvas, материалы, геометрия и render target освобождаются.

После интро нет тоннелей, дополнительных чёрных дыр и закреплённых scroll-driven проходов. Главный экран, разделы и галерея находятся в обычном потоке. Сохранены заголовок «За пределами обычного», кнопки, палитра и исходная геометрия энергетического объекта. Курсор мягко влияет на его вращение; клик, Enter или пробел плавно меняют ограниченную форму без движения камеры. Область модели отделена от текста.

## Проекты

Контент — в `src/projects.ts`. Реальные ссылки сохранены:

- AURA BEAUTY: https://amazing-pony-95fbe1.netlify.app/
- NEXORA DIGITAL: https://lambent-pudding-e679ea.netlify.app/

Галерея сохраняет существующие объёмные панели и лёгкий наклон. Проекты выбираются кнопками и стрелками; принудительной прокрутки нет. `YOUR NEXT IDEA` ведёт к контактам. Активный снимок отображается через MeshBasicMaterial без коррекции экспозиции, с sRGB и anisotropy до 8.

**В репозитории пока нет реальных скриншотов:** `public/projects/screenshots.json` пуст. Поэтому видны светлые подписанные обложки «не скриншот»; они не имитируют интерфейсы реальных работ. `npm run check:captures` сообщает об отсутствии двух изображений. Проверенные запросы к обоим Netlify-доменам возвращают CONNECT 403 от облачного прокси.

После разрешения доменов в настройках среды можно получить настоящие снимки:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run capture:projects
npm run check:captures
npm run build
```

Захват проверяет HTTP-ответ, название бренда и загрузку видимых изображений, затем сохраняет WebP 1600×1000, URL источника, дату и SHA-256 оригинала. Ошибочные страницы не выдаются за скриншоты. Допустимо добавить предоставленные владельцем реальные снимки в `public/projects` и соответствующий манифест.

## Скульптуры и кубик

Исходная геометрия хромированного узла и стеклянного многогранника сохранена. Доступно перетаскивание и вращение стрелками. Белый кубик с чёрными разделителями не имеет кнопок управления: шесть ходов перемешивания, шесть обратных ходов, пауза 1,15 секунды в собранном состоянии. Поворот длится 0,3 секунды, короткий промежуток между ходами — 0,065 секунды. Существующая временная группа поворачивает 9 деталей, затем фиксирует целочисленные координаты без накопления погрешности. Одновременно выполняется только один ход.

Непрерывно отрисовывается один видимый WebGL-объект; остальные сохраняют кадр. PAUSE, скрытая вкладка, выход из viewport и reduced motion останавливают постоянную отрисовку. Материалы и геометрия переиспользуются, обработчики и ресурсы очищаются. Частота кадров на физическом мобильном GPU требует отдельной проверки.

## Проверки

```sh
npm run test:models
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

Если системного Chromium нет: `npx playwright install chromium`, затем `npm run test:browser` без переопределения пути. Скрипт сам запускает и останавливает dev/preview на портах 5175/4175.

Модульные тесты проверяют геометрию, точность поворотов и обратной сборки, независимость от интервала кадров, непрерывность intro-перехода. Браузерный прогон отдельно проверяет первое и повторное посещение, preview без изменения sessionStorage, пропуск, обычный скролл, обе ссылки проектов, контакты, мобильную раскладку, reduced motion, реальные WebGL-объекты и локальные fallback. Ошибки в консоли в сценариях искусственных отказов ожидаемы; в обычном режиме проверяется их отсутствие. В облачном Chromium используется SwiftShader: это функциональная проверка, не подтверждение FPS на физическом GPU.

Для короткого профиля **главного объекта и кубика** запустите preview, затем:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run profile:scenes -- final http://localhost:4173
```

JSON/PNG пишутся во временную папку ОС или `NIKOLAY_PROFILE_DIR`. Прежние измерения scroll-driven TON в `docs/scene-measurements.json` относятся к предыдущей версии и не характеризуют текущий сайт. Текущая проверка описана в `docs/QUALITY_REPORT.md`.
